# Бюро находок: практическая 04

Этот проект содержит готовую практическую 03. Новые задания помечены TODO P04-. Полный текст работы находится в отдельном PDF.

## Запуск

1. Распакуйте проект в новую папку, не поверх работы 03. Скопируйте свой variant.json из работы 03. Если варианта ещё нет, выполните npm run variant.
2. Используйте Node.js 24 LTS. Зависимости закреплены в package-lock.json; npm ci устанавливает их без смены версий. .npmrc уже содержит совместимые настройки установки.
3. Для Atlas перенесите свою строку подключения в .env.local как MONGODB_URI=... . Этот файл не добавляется в Git. Не копируйте чужие пароли. Без этой переменной работает память сервера, очищаемая после его перезапуска.
4. В терминале папки проекта: npm ci, затем npm run start. Для браузера нажмите w. Для Expo Go используйте npm run tunnel; остановите прежний сервер Ctrl+C перед сменой проекта.
5. npm run typecheck проверяет типы. npm run check обращается к серверу http://localhost:8081; другой адрес передайте аргументом: npm run check -- http://localhost:8082.

Самопроверка создаёт одну учебную находку с вымышленным номером +70000000000. Она не заменяет показ формы и хранилищ на телефоне.

## Что реализовать

- P04-SCHEMA: src/forms/itemSchema.ts, createItemSchema.
- P04-FORM: src/forms/DescriptionField.tsx и src/forms/submitReport.ts.
- P04-SERVER: POST в src/app/api/items+api.ts.
- P04-DRAFT: src/storage/draftStore.ts.
- P04-CONTACT: src/storage/phoneStore.ts.

Стартовые заглушки компилируются, показывают свои коды этапов и не изображают успешное сохранение. Не изменяйте готовую очередь draftSession.ts: она не позволяет старой записи восстановить уже удалённый черновик.
